# 开源视觉微信小程序

这是 Oraen View 的微信小程序版本，只包含适合手机使用的“掌上训练”和“训练数据”。

## 功能

- 综合训练：单图、三图、清晰图、移图各 64 次，共 256 次。
- 单项训练：每次固定 64 次。
- 自适应难度：同一模式连续正确两次后变难，错误一次后变简单。
- 刺激方向：每次刺激从 0°、45°、90°、135° 中独立随机选择；连续三次错误时提醒重新注视中心。
- 帧提示：刺激出现时，画布四边的红框与图像在同一帧绘制。
- 本地记录：训练会话、逐题结果、正确率和四项难度曲线均保存在微信本地。
- 数据隔离：使用 `oraenViewWechat:v1` 命名空间，不读取网页端或小红书端数据。
- 隐私接口：不调用登录、用户资料、设备信息、剪贴板、位置、相册、摄像头或网络接口。

## 打开方式

使用微信开发者工具导入 `mini` 目录。项目入口由 `project.config.json` 指向 `miniprogram/`，无需云函数，也没有网络请求。

微信官方示例工程原有的演示页面、组件、依赖和云函数已经移除。上传前请在开发者工具中执行“代码质量”和真机预览，重点检查不同手机上的刺激尺寸、帧时序与触摸作答。

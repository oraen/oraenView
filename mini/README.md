# 开源视觉微信小程序

这是 Oraen View 的微信小程序版本，包含掌上训练、弱视小游戏和训练数据。

## 功能

- 综合训练：单图、三图、清晰图、移图各 64 次，共 256 次。
- 单项训练：每次固定 64 次。
- 自适应难度：同一模式连续正确两次后变难，错误一次后变简单。
- 刺激方向：每次刺激从 0°、45°、90°、135° 中独立随机选择；连续三次错误时提醒重新注视中心。
- 帧提示：刺激出现时，画布四边的红框与图像在同一帧绘制。
- 本地记录：训练会话、逐题结果、正确率和四项难度曲线均保存在微信本地。
- 数据隔离：使用 `oraenViewWechat:v1` 命名空间，不读取网页端或小红书端数据。
- 隐私接口：不调用登录、用户资料、设备信息、剪贴板、位置、相册、摄像头或网络接口。
- 弱视小游戏：十二个原创 Canvas 游戏，每局 24 题、1–30 级，连续答对两题升级、答错一题降级；支持暂停、退出、声音反馈和连续三次错误提醒。
- 红青训练：红蓝合环、红蓝寻宝和红蓝深度球需自备红青眼镜，首次进入会记录红色镜片方向和弱视眼；另一眼通道默认使用 0.55 对比权重。
- 儿童数据：使用独立的 `oraenViewWechat:child:v1` 命名空间，与 `oraenViewWechat:v1` 掌上数据互不读取、覆盖或清空。数据页可切换查看十二项等级、正确率、游戏分布、趋势、会话和逐题明细。

## 打开方式

使用微信开发者工具导入 `mini` 目录。项目入口由 `project.config.json` 指向 `miniprogram/`，无需云函数，也没有网络请求。

微信官方示例工程原有的演示页面、组件、依赖和云函数已经移除。上传前请在开发者工具中执行“代码质量”和真机预览，重点检查不同手机上的刺激尺寸、帧时序与触摸作答。

`miniprogram/` 当前约 149 KB，远低于 2 MB 主包限制。运行 `npm --prefix mini test` 可检查公共规则、成人/儿童存储隔离、训练参数和页面关键行为。红青颜色分离、不同机型 Canvas 点击坐标、横竖屏切换和音量仍需在微信开发者工具及至少一台 iPhone、一台 Android 真机确认。

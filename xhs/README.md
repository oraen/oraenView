# 开源视觉 · 小红书小工具

上传 **`oraen-view-xhs.zip`** 即可，不要上传整个 `xhs` 文件夹。ZIP 根目录就是 `index.html`。

`app/` 是可独立维护的小工具源码和静态资源。没有在线依赖，也没有服务器程序。网站的 `public/` 未改动，网站构建仍只发布 `dist/public`。

## 保留的功能

- 掌上训练：综合、单图、三图、清晰图、移图；单项各 64 次，综合四项各 64 次，共 256 次。
- 与网页版相同的 Gabor 参数、出题顺序、呈现时长、左右键映射和自适应规则：连续答对两次变难，答错一次变简单；每次刺激会从 0°、45°、90°、135° 中独立随机选择方向；刺激出现时四边红框同步闪烁；连续三次错误时提醒重新注视中心；完成训练后继承对应模式难度。
- 正确率、上次训练记录、看不清时凭感觉猜的提示。
- 训练数据：当前累计难度、正确率趋势、模式表现、会话记录、分页、搜索、明细、四项难度曲线、刷新和清空。保留最近 100 场。
- 首次打开直接进入掌上训练，无版权或使用协议确认弹窗。未完成的训练不改变继承难度；离开训练页、切到后台或改变窗口尺寸时结束当前训练。

## 按容器规则做的调整

- 只保留两个页面，不包含电脑版训练、视觉测试、使用指引、关于项目或电脑版数据标签。
- 使用普通外置脚本、相对路径及 ES2017 写法；不使用模块加载、网络请求、系统全屏或文件下载。
- JSON 导出已移除，小工具不展示开发者名片。
- 数据库为 `oraenViewXhsDB`，难度键为 `xhs:adaptiveLevels:local-user`，不读取、迁移或修改网站电脑版、手机版的数据库。小工具缓存可能被平台清理，不保证永久保存。
- 使用 Canvas 2D，画布逻辑尺寸仍为 480×480；按实际可用区域等比例显示。Flex 间距、画布尺寸、安全区和弹层提供 Chrome 61 基线写法。

## 检查结果与限制

- 已在本机 Chrome 使用严格 CSP 和受限 API 模拟检查：经典脚本加载、无外部请求、五种模式共 512 次作答、曲线、刷新恢复、明细、清空。
- 已检查 `file://` 离线入口启动。体积审计无错误、无警告；包体约 72 KB。
- 已静态核对资源路径、禁用能力及使用到的新语法/API；这不能替代旧内核实测。
- **尚未在小红书官方模拟器、真机容器或 Chrome 61 / Android 8.1 实测；CSS 兼容性、真机性能和帧呈现时长未实测。** 上传后请先预览并在真机确认画面、左右键、横竖屏、后台返回与记录持久化。现代 Chrome 测试通过不代表平台审核通过。

## 重新打包

在项目根目录运行：

```sh
python xhs/tools/package.py
```

此脚本只压缩 `app/` 的内容，不会带入说明、截图或开发脚本。打包后还需运行 skill 附带的 `audit_artifact.py`，分别审计 `xhs/app` 和最终 ZIP。

本地开发检查（使用项目已有的 Playwright 和 Chrome）：

```sh
node xhs/tools/test.mjs
node xhs/tools/test.mjs --full
```

`--full` 仅在测试服务中缩短刺激等待时间，不改变上传包。普通检查使用实际训练时长。

`tools/adapt.py` 是首次从网页提取代码的适配脚本，依赖本机已有的 BeautifulSoup；运行会重新生成部分 `app/` 文件。日常修改可直接编辑 `app/`，无需运行适配脚本、无需安装构建依赖。

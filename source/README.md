# Gabor training demo assets

这些文件是原创示例资源，用来模拟 Gabor 视觉刺激和侧向掩蔽训练界面，不是任何第三方网站素材的复制品。

- `gabor_generator.html`: Canvas 参数生成器，可动态调整对比度、空间频率、方向、清晰范围、背景灰度和单图/三图模式。
- `gabor_single_low_contrast.svg`: 单个低对比 Gabor 示例。
- `gabor_triple_lateral_masking.svg`: 三联侧向掩蔽示例，中间目标更低对比度。
- `gabor_shifted_choices.svg`: 四选一/偏移和对比度判断示例。

直接用浏览器打开 `gabor_generator.html` 即可调参数并导出 PNG。
